# DataStrategist Checklist

**Agent:** DataStrategist  
**Version:** 1.0

---

## Problem Statement Checklist

### Business Context
- [ ] Business domain/area identified
- [ ] Current situation described
- [ ] Industry context provided (if relevant)
- [ ] Historical context included

### Problem Definition
- [ ] Core problem clearly stated
- [ ] Problem is specific, not vague
- [ ] Symptoms identified
- [ ] Root causes analyzed
- [ ] Duration of problem noted

### Impact Analysis
- [ ] Financial impact quantified
- [ ] Operational impact described
- [ ] Customer/user impact documented
- [ ] Opportunity costs identified
- [ ] Risk of inaction stated

### Scope Definition
- [ ] In-scope items listed
- [ ] Out-of-scope items listed
- [ ] Constraints documented
- [ ] Assumptions stated

### Stakeholders
- [ ] Business owner identified
- [ ] Primary users identified
- [ ] Approvers identified
- [ ] Data providers identified

---

## KPI Checklist

### Quantity and Coverage
- [ ] At least 3 KPIs defined
- [ ] KPIs cover multiple dimensions
- [ ] KPIs align with problem statement

### KPI Completeness (per KPI)
- [ ] Clear name and description
- [ ] Baseline value documented
- [ ] Target value set
- [ ] Timeframe defined
- [ ] Calculation formula provided
- [ ] Data sources identified
- [ ] Measurement frequency specified
- [ ] Owner assigned

### Quality Criteria
- [ ] KPIs are Specific
- [ ] KPIs are Measurable
- [ ] KPIs are Achievable
- [ ] KPIs are Relevant
- [ ] KPIs are Time-bound

---

## Success Criteria Checklist

### Structure
- [ ] At least 2 "Must Have" criteria
- [ ] Criteria prioritized (Must/Should/Nice)
- [ ] Criteria linked to KPIs

### Criterion Completeness
- [ ] Clear description
- [ ] Measurable threshold
- [ ] Validation method specified
- [ ] Approver identified
- [ ] Evidence requirements listed

### Process
- [ ] Sign-off authority defined
- [ ] Validation timeline set
- [ ] Status tracking in place

---

## Stakeholder Map Checklist

### Identification
- [ ] All stakeholder groups listed
- [ ] Names or roles specified
- [ ] Contact information available

### Analysis
- [ ] Interest level assessed
- [ ] Influence level assessed
- [ ] RACI matrix created

### Communication
- [ ] Communication plan defined
- [ ] Frequency established
- [ ] Channels identified

---

## Strategy Summary Checklist

### Content
- [ ] Executive summary present
- [ ] Problem overview included
- [ ] KPI summary included
- [ ] Success criteria summarized
- [ ] Next steps clear

### Review
- [ ] Reviewed by business owner
- [ ] Approved by stakeholders
- [ ] Version controlled

---

## Gate 1 Readiness Checklist

### Required Artifacts
- [ ] Problem Statement complete
- [ ] KPIs documented
- [ ] (Optional) Success Criteria defined

### Quality Checks
- [ ] Problem statement > 500 characters
- [ ] At least 3 KPIs with all fields
- [ ] Impact is quantified

### Handoff Preparation
- [ ] Context for BusinessAnalyst prepared
- [ ] Key decisions documented
- [ ] Open questions listed

---

## Common Issues to Avoid

### Problem Statement
- ❌ Vague problem description
- ❌ Missing quantified impact
- ❌ Unclear scope boundaries
- ❌ No stakeholders identified

### KPIs
- ❌ Fewer than 3 KPIs
- ❌ Missing baseline values
- ❌ No calculation formula
- ❌ Unmeasurable metrics

### Success Criteria
- ❌ No "Must Have" criteria
- ❌ Non-measurable criteria
- ❌ No validation method
- ❌ No approver defined
