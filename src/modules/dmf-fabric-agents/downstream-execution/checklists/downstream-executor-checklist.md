# Downstream Executor Checklist

## Before Execution

- [ ] Gate 2 artifacts approved
- [ ] DDL and ETL package prepared
- [ ] Test plan prepared
- [ ] Rollback validated
- [ ] Execution window approved

## During Execution

- [ ] Pre-flight checks completed
- [ ] DDL executed in order
- [ ] ETL executed in order
- [ ] Quality checks executed
- [ ] Reconciliation triggered

## After Execution

- [ ] Wave report published
- [ ] Runbook updated with lessons learned
- [ ] Open issues routed to responsible agents
