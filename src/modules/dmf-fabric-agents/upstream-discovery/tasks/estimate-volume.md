# Task: Estimate Data Volumes & Transfer Times

```yaml
task_id: estimate-volume
agent: discovery-scout
version: "4.0"
command: "*estimate-volume"
phase: UPSTREAM
gate: 1
output: "data-volume-estimate.json"
output_folder: "projects/{project_name}/outputs/upstream/discovery/volume-estimates/"
```

---

## Purpose

Estimate total data volumes across all tables and databases in the legacy environment. Calculate partition counts, compression ratios, and estimated transfer times based on available bandwidth. This data feeds into migration planning for capacity, scheduling, and cost estimation.

---

## Pre-Conditions

- [ ] `inventory.json` generated by `*scan-repo` task
- [ ] Access to table metadata (sizes, row counts, partitions)
- [ ] Network bandwidth estimate (optional — defaults to 100 Mbps)

---

## Execution Steps

### Step 1 — Query Table Sizes

```
1.1  Load inventory.json
1.2  For each database/schema:
     - Query table sizes (bytes, MB, GB, TB)
     - Query row counts
     - Query partition counts
     - Query compression type and ratio
1.3  For tables without direct size queries:
     - Estimate from row count × average row size
     - Mark as ESTIMATED vs MEASURED
1.4  Log totals per database
```

### Step 2 — Calculate Partition Metrics

```
2.1  For each partitioned table:
     - Count total partitions
     - Calculate average partition size
     - Identify partition key and type (date, hash, range)
     - Estimate partition growth rate
2.2  Flag tables with excessive partitions (> 10,000)
2.3  Flag tables with skewed partitions (max/min ratio > 10x)
```

### Step 3 — Estimate Transfer Times

```
3.1  Define bandwidth assumptions:
     - Default: 100 Mbps effective throughput
     - Conservative: 50 Mbps (shared network)
     - Optimistic: 500 Mbps (dedicated link)
3.2  For each table:
     transfer_time = size_bytes / (bandwidth_bps / 8)
3.3  Calculate total transfer time:
     - Serial (one table at a time)
     - Parallel (4 concurrent streams)
     - Parallel (8 concurrent streams)
3.4  Add 20% overhead for metadata operations
```

### Step 4 — Generate Volume Report

```
4.1  Compile data-volume-estimate.json with:
     - Per-database volume summary
     - Per-table detail (top 50 largest)
     - Partition statistics
     - Transfer time estimates (3 scenarios)
     - Total volume across environment
4.2  Generate recommendations:
     - Tables to compress before transfer
     - Tables to partition differently
     - Tables to transfer first (dependencies)
     - Tables to exclude (dead code)
4.3  Save to projects/{project_name}/outputs/upstream/discovery/volume-estimates/
```
