# Dashboard Review Checklist

## Visual Hierarchy
- [ ] Most important information visible first (top-left)
- [ ] KPIs have comparison context (vs target, vs prior period)
- [ ] Clear flow from summary to detail
- [ ] Visual grouping makes logical sense

## Chart Selection
- [ ] Chart types appropriate for data being shown
- [ ] No pie charts with >7 categories
- [ ] Bar charts used for comparison (not line)
- [ ] Line charts used for trends over time
- [ ] Maps used only for geographic data

## Color Usage
- [ ] Color palette is consistent
- [ ] Color has meaning (not decorative)
- [ ] Red/green used appropriately for negative/positive
- [ ] Color blind accessible
- [ ] Not more than 7 distinct colors

## Labeling & Formatting
- [ ] All visuals have clear titles
- [ ] Numbers properly formatted (currency, %, etc.)
- [ ] Data labels not overlapping
- [ ] Axis labels clear and readable
- [ ] Legend positioned appropriately

## Interactivity
- [ ] Slicers are intuitive
- [ ] Cross-filtering behavior is appropriate
- [ ] Drill-down paths are clear
- [ ] Tooltips provide additional value

## Performance
- [ ] Page loads in <5 seconds
- [ ] No more than 8-10 visuals per page
- [ ] No unnecessary visuals

## Mobile
- [ ] Mobile layout created
- [ ] Critical KPIs visible on mobile
- [ ] Touch-friendly interactions

## Accessibility
- [ ] Alt text on all visuals
- [ ] Sufficient contrast ratios
- [ ] Information not conveyed by color alone
