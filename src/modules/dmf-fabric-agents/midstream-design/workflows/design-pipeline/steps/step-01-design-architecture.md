# Step 01 — Design Architecture

**Agente:** data-architect  
**Task:** create-architecture  
**Input:** `outputs/upstream/sttm.md`, `digital-twin.json`  
**Output:** `outputs/midstream/architecture.md`

## Instrução
Ativar `data-architect` e executar `*create-architecture`. O agente define a arquitetura de dados target (camadas Bronze/Silver/Gold ou equivalente), decisões técnicas (ADRs) e diagrama de componentes.

## Critério de Conclusão
- [ ] `architecture.md` com todas as camadas definidas
- [ ] ADRs documentados para decisões críticas
- [ ] Diagrama de componentes presente
