---

## Purpose

Guide the user through identifying and documenting Key Performance Indicators (KPIs) that will measure success for the data initiative.

---

## Prerequisites

- Problem statement completed (recommended)
- Understanding of business objectives
- Access to current metrics/data sources

---

## Execution Steps

### Step 1: Review Problem Context

If problem statement exists, review it to understand:
- Business objectives
- Desired outcomes
- Current pain points

### Step 2: Identify Success Dimensions

Ask the user:
1. What does success look like for this initiative?
2. What aspects of the problem should improve?
3. What would stakeholders want to see measured?

**Common Dimensions:**
- Financial (revenue, cost, profit)
- Operational (efficiency, speed, quality)
- Customer (satisfaction, retention, growth)
- Compliance (risk, accuracy, coverage)

### Step 3: Define Specific KPIs

For each dimension, create specific, measurable KPIs.

**SMART Criteria:**
- **S**pecific: Clear and unambiguous
- **M**easurable: Quantifiable
- **A**chievable: Realistic target
- **R**elevant: Aligned to objectives
- **T**ime-bound: Has a timeframe

### Step 4: Establish Baselines

For each KPI, determine:
1. Current value (baseline)
2. How it's currently measured
3. Data source for baseline

**If baseline unknown:**
- Note as "TBD - to be measured"
- Plan for baseline measurement

### Step 5: Set Targets

For each KPI, define:
1. Target value
2. Timeframe for achieving target
3. Interim milestones (if applicable)

### Step 6: Document Calculations

For each KPI, document:
1. Formula/calculation method
2. Data sources needed
3. Measurement frequency

### Step 7: Generate KPIs Document

## KPI Categories Reference

### Financial KPIs
| Example | Formula |
|---------|---------|
| Revenue Impact | New Revenue - Baseline Revenue |
| Cost Savings | Baseline Cost - New Cost |
| ROI | (Gain - Cost) / Cost × 100% |

### Operational KPIs
| Example | Formula |
|---------|---------|
| Processing Time | End Time - Start Time |
| Throughput | Records Processed / Time Period |
| Error Rate | Errors / Total Records × 100% |

### Customer KPIs
| Example | Formula |
|---------|---------|
| Satisfaction Score | Survey Average |
| Retention Rate | Retained / Total × 100% |
| Response Time | Time to Resolution |

### Data Quality KPIs
| Example | Formula |
|---------|---------|
| Completeness | Non-Null / Total × 100% |
| Accuracy | Correct / Total × 100% |
| Timeliness | On-Time / Total × 100% |

## Validation Checklist

Before completing, verify:

- [ ] At least 3 KPIs defined
- [ ] Each KPI has baseline (or plan to measure)
- [ ] Each KPI has target value
- [ ] Each KPI has calculation formula
- [ ] Data sources identified
- [ ] Measurement frequency defined
- [ ] KPIs align with problem statement
