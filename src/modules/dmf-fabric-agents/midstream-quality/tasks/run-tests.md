# ✅ Task: Run Tests

> **Command:** `*run-tests`
> **Agent:** Vera (Quality Gate)
> **Phase:** MIDSTREAM | **Gate:** 2

---

## Objective

Execute the pytest suite generated by Coda ⚙️ for a given pipeline. Collect test results, measure line and branch coverage, identify failures, and produce a structured test results report.

---

## Prerequisites

- [ ] Generated code available: `generated-code/{pipeline_id}.py`
- [ ] Generated tests available: `generated-tests/{pipeline_id}_test.py`
- [ ] pytest installed with required plugins (`pytest-cov`, `pytest-json-report`)
- [ ] Spark test environment available (local SparkSession or mock)
- [ ] Minimum coverage threshold loaded (default: 80%)

---

## Steps

### Step 1: Validate Test File

Verify the test file exists, is valid Python, and contains test functions.

```
Load: generated-tests/{pipeline_id}_test.py

Validate:
  - File exists and is non-empty
  - Python AST parses successfully
  - Contains at least one function starting with test_
  - Contains pytest imports
  - Has appropriate fixtures (SparkSession, sample data)
```

**Pass Criteria:** Test file is valid and contains ≥ 1 test function.
**Fail Action:** REJECT with `invalid_test_file` error.

---

### Step 2: Setup Test Environment

Prepare the test execution environment.

```
Setup:
  1. Create isolated temp directory for test execution
  2. Copy code file and test file to temp directory
  3. Set PYTHONPATH to include code directory
  4. Configure SparkSession for local testing:
     - spark.master = "local[2]"
     - spark.sql.shuffle.partitions = 2
     - spark.driver.memory = "2g"
     - spark.sql.extensions = "io.delta.sql.DeltaSparkSessionExtension"
  5. Create temp Delta Lake directory for write tests
```

---

### Step 3: Execute pytest

Run the test suite with coverage measurement.

```
Command:
  pytest {test_file} \
    --json-report \
    --json-report-file={output_dir}/test_report.json \
    --cov={module_name} \
    --cov-report=json:{output_dir}/coverage.json \
    --cov-report=term-missing \
    --cov-branch \
    -v \
    --tb=long \
    --timeout=300

Capture:
  - stdout and stderr
  - Exit code
  - Execution time per test
```

**Timeout:** 5 minutes (300 seconds). If exceeded, REJECT with `test_timeout`.

---

### Step 4: Parse Test Results

Extract structured results from the pytest JSON report.

```
Parse: test_report.json

Extract:
  summary:
    total: int
    passed: int
    failed: int
    errors: int
    skipped: int
    duration: float (seconds)

  tests: [
    {
      name: str
      outcome: "passed" | "failed" | "error" | "skipped"
      duration: float
      message: str (if failed)
      traceback: str (if failed)
    }
  ]
```

---

### Step 5: Parse Coverage Results

Extract coverage metrics from the coverage JSON report.

```
Parse: coverage.json

Extract:
  overall_coverage:
    line_rate: float (0.0–1.0)
    branch_rate: float (0.0–1.0)
    lines_covered: int
    lines_total: int
    branches_covered: int
    branches_total: int

  uncovered_lines: [int]
  uncovered_branches: [{"line": int, "branch": str}]

  per_function_coverage: [
    { function_name: str, line_rate: float, missing_lines: [int] }
  ]
```

---

### Step 6: Analyze Test Quality

Evaluate the quality and completeness of the test suite.

```
Check 6a: Test Categories
  - Positive tests (happy path): min 60% of total
  - Negative tests (error handling): min 20% of total
  - Edge case tests (nulls, empty, boundaries): min 10% of total

Check 6b: Fixture Quality
  - SparkSession fixture uses local mode
  - Sample data covers representative scenarios
  - Fixtures are properly scoped (session/function)

Check 6c: Assertion Quality
  - Tests use specific assertions (not just assert True)
  - Schema assertions present
  - Row count assertions present
  - Value assertions present for key transformations

Check 6d: Missing Test Coverage
  Identify code paths not covered by tests:
  - Untested functions
  - Untested branches (if/else)
  - Untested error handlers
```

---

### Step 7: Calculate Test Score

Produce a final test dimension score.

```python
pass_rate = passed / total * 100
coverage_pct = line_rate * 100

# Score calculation
if pass_rate == 100 and coverage_pct >= 90:
    test_score = 10.0
elif pass_rate == 100 and coverage_pct >= 80:
    test_score = 9.0
elif pass_rate == 100 and coverage_pct >= 70:
    test_score = 7.5
elif pass_rate >= 90 and coverage_pct >= 80:
    test_score = 6.0
else:
    test_score = 3.0

# Adjust for test quality
if test_quality_issues:
    test_score -= 0.5 * len(test_quality_issues)
    test_score = max(test_score, 0.0)
```

**Pass Criteria:** 100% pass rate AND coverage ≥ 80%
**Fail Action:** REJECT if any test fails. Flag if coverage < 80%.

---

### Step 8: Generate Test Results Report

Create structured report and save to output folder.

```
Output: projects/{project_name}/outputs/midstream/quality/test-results/{pipeline_id}_test_results.json
Template: templates/test-results-tmpl.md
```

## Error Handling

| Error                        | Action                                         |
|------------------------------|-------------------------------------------------|
| Test file not found          | REJECT with `missing_test_file` error           |
| Test file has syntax errors  | REJECT with `test_syntax_error` error           |
| SparkSession setup fails     | Retry with reduced config, then REJECT          |
| pytest timeout (> 5 min)     | REJECT with `test_timeout` error                |
| Coverage plugin not installed| Install `pytest-cov`, retry                     |
| Out of memory                | Reduce parallelism, retry with `local[1]`       |
