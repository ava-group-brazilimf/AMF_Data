# Task: Detect Dead Code — Find Orphan & Unused Objects

```yaml
task_id: detect-dead-code
agent: discovery-scout
version: "4.0"
command: "*detect-dead-code"
phase: UPSTREAM
gate: 1
output: "dead-code-report.md"
output_folder: "projects/{project_name}/outputs/upstream/discovery/dead-code-reports/"
```

---

## Purpose

Identify all dead code in the legacy environment — orphan tables with no upstream/downstream references, unused scripts never called by any pipeline, and deprecated jobs that haven't executed in a defined period. Dead code can be excluded from migration scope, reducing effort and cost.

---

## Pre-Conditions

- [ ] `inventory.json` generated by `*scan-repo` task
- [ ] `dependency-graph.json` generated by `*map-dependencies` task
- [ ] Access to execution logs or last-access metadata (optional but recommended)

---

## Execution Steps

### Step 1 — Identify Orphan Tables

```
1.1  Load dependency-graph.json
1.2  For each table node in the graph:
     - Check in_degree (upstream references)
     - Check out_degree (downstream references)
1.3  Flag as ORPHAN if:
     - in_degree == 0 AND out_degree == 0 (completely isolated)
     - OR no pipeline/job references the table
1.4  Collect orphan table metadata:
     - Name, database, size, row count
     - Creation date, last modified date
     - Owner
1.5  Log total orphan tables found
```

### Step 2 — Identify Unused Scripts

```
2.1  For each script in the inventory:
     - Search for references in all pipelines and jobs
     - Check import statements across all code files
     - Search for direct file path references
2.2  Flag as UNUSED if:
     - No pipeline or job references the script
     - No import statement references the module
     - No scheduled execution in the last 180 days
2.3  Collect unused script metadata
2.4  Log total unused scripts found
```

### Step 3 — Identify Deprecated Jobs

```
3.1  For each job in the inventory:
     - Check last execution date
     - Check execution status history
     - Check if job is disabled/paused
3.2  Flag as DEPRECATED if:
     - Last execution > 90 days ago AND status = DISABLED
     - OR last execution > 180 days ago (regardless of status)
     - OR marked with deprecation tag in metadata
3.3  Collect deprecated job metadata
3.4  Log total deprecated jobs found
```

### Step 4 — Cross-Reference Analysis

```
4.1  Cross-reference orphan tables against:
     - Unused scripts (scripts that create orphan tables)
     - Deprecated jobs (jobs that populated orphan tables)
4.2  Identify dead code clusters (related dead objects)
4.3  Calculate total storage consumed by dead code
4.4  Calculate potential migration scope reduction
```

### Step 5 — Generate Report

```
5.1  Generate dead-code-report.md using template
5.2  Include:
     - Summary statistics
     - Orphan tables list with details
     - Unused scripts list with details
     - Deprecated jobs list with details
     - Dead code clusters
     - Recommendations (exclude from migration scope)
     - Storage savings estimate
5.3  Save to projects/{project_name}/outputs/upstream/discovery/dead-code-reports/
```

---

## Classification Criteria

| Category         | Criteria                                             | Confidence |
|------------------|------------------------------------------------------|------------|
| **ORPHAN_TABLE** | No upstream/downstream references, isolated in graph | HIGH       |
| **UNUSED_SCRIPT**| No pipeline/job reference, no imports found          | HIGH       |
| **DEPRECATED_JOB**| Disabled + no execution > 90 days                  | HIGH       |
| **STALE_TABLE**  | Has references but no writes > 180 days              | MEDIUM     |
| **SUSPECT_SCRIPT**| Only 1 reference, last run > 90 days               | LOW        |
