# ⚙️ Task: Generate Job Definition

> **Command:** `*generate-job`
> **Agent:** Coda (Code Generator)
> **Phase:** MIDSTREAM | **Gate:** 2

---

## Objective

Create a Databricks job JSON definition for the generated pipeline code. The job definition includes scheduling, cluster configuration, parameters, alerts, and retry policies.

---

## Prerequisites

- [ ] Generated code exists: `projects/{project_name}/outputs/midstream/generated-code/{pipeline_id}.py`
- [ ] Legacy schedule information available from pseudocode
- [ ] Target cluster configuration defined in `target-config.yaml`

---

## Steps

### Step 1: Map Schedule from Legacy

Extract and convert the legacy scheduling information to Databricks cron format.

```
Legacy Schedule Analysis:
  - Source system schedule (SAP Process Chain, BODS, etc.)
  - Frequency: daily, hourly, weekly, event-driven
  - Time windows: batch windows, dependencies
  - Timezone: convert to UTC or target timezone

Conversion:
  SAP Process Chain → Cron expression
  BODS Schedule     → Cron expression
  Manual trigger    → On-demand (no schedule)
```

| Legacy Type          | Databricks Equivalent                    |
|---------------------|------------------------------------------|
| Daily batch         | `0 0 6 * * ?` (6 AM daily)              |
| Hourly incremental  | `0 0 * * * ?` (every hour)              |
| Weekly report       | `0 0 2 ? * MON` (Monday 2 AM)           |
| Event-driven        | Triggered via API / webhook              |
| Real-time           | Streaming job (continuous)               |

---

### Step 2: Configure Cluster

Define the compute cluster specification for the job.

```yaml
cluster_spec:
  spark_version: "13.3.x-scala2.12"
  node_type_id: "Standard_DS3_v2"        # Azure
  num_workers: 2                           # Default, auto-scale
  autoscale:
    min_workers: 1
    max_workers: 8
  spark_conf:
    "spark.sql.adaptive.enabled": "true"
    "spark.sql.adaptive.coalescePartitions.enabled": "true"
    "spark.databricks.delta.optimizeWrite.enabled": "true"
    "spark.databricks.delta.autoCompact.enabled": "true"
  custom_tags:
    project: "migration-factory"
    pipeline: "{pipeline_id}"
    environment: "production"
```

**Sizing Rules:**
| Data Volume    | Workers | Node Type         |
|---------------|---------|-------------------|
| < 1 GB        | 1-2     | Standard_DS3_v2   |
| 1-10 GB       | 2-4     | Standard_DS4_v2   |
| 10-100 GB     | 4-8     | Standard_DS5_v2   |
| > 100 GB      | 8-16    | Standard_E8s_v3   |

---

### Step 3: Set Parameters

Define job parameters and widget configurations.

```json
{
  "parameters": [
    {
      "name": "environment",
      "default": "production",
      "description": "Target environment (dev/staging/production)"
    },
    {
      "name": "load_date",
      "default": "{{date:yyyy-MM-dd}}",
      "description": "Processing date for incremental loads"
    },
    {
      "name": "source_schema",
      "default": "raw",
      "description": "Source schema/catalog name"
    },
    {
      "name": "target_schema",
      "default": "curated",
      "description": "Target schema/catalog name"
    }
  ]
}
```

---

### Step 4: Add Alerts and Notifications

Configure monitoring, alerts, and notification channels.

```json
{
  "email_notifications": {
    "on_start": [],
    "on_success": ["data-team@company.com"],
    "on_failure": ["data-team@company.com", "oncall@company.com"],
    "no_alert_for_skipped_runs": true
  },
  "webhook_notifications": {
    "on_failure": [
      {
        "id": "teams-webhook-id"
      }
    ]
  },
  "timeout_seconds": 3600,
  "max_retries": 2,
  "min_retry_interval_millis": 300000,
  "retry_on_timeout": true
}
```

```json
}
```
